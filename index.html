ESPie iButton Key Tool

Портативное устройство на базе ESP8266 для чтения, эмуляции и брутфорса ключей iButton серии DS1990A/DS2401. Управление через OLED-дисплей и 4 кнопки.

Что умеет ESPie

📖
READ KEY
Считать ключ iButton с шины OneWire через GPIO0. Результат сохраняется в EEPROM (до 10 ключей).
✓ РАБОТАЕТ
📡
EMULATE
Эмуляция ключа из памяти на GPIO2 в течение 10 секунд. Выбор ключа кнопками UP/DOWN.
✓ РАБОТАЕТ
🔓
BRUTFORCE
Перебор 27 встроенных ключей + все сохранённые пользователем. Интервал 500 мс.
✓ РАБОТАЕТ
👁️
VIEW CODE
Просмотр HEX-кода ключа с проверкой CRC. Удобно для верификации считанных ключей.
✓ РАБОТАЕТ
🗑️
DELETE
Удаление ключей из EEPROM. Управление сохранёнными записями через меню устройства.
✓ РАБОТАЕТ
💾
WRITE KEY
Запись ключа на перезаписываемую метку DS1990A. Реализация протокола в разработке.
⚠ В РАЗРАБОТКЕ

Компоненты и распиновка

МК ESP8266 (NodeMCU / Wemos D1 Mini)
Дисплей OLED 128×64, SSD1306, I2C
Кнопки 4 шт. (UP, DOWN, OK, BACK)
Интерфейс GPIO0 — чтение, GPIO2 — эмуляция
Питание TP4056 + Li-Ion батарея
Память ключей До 10 ключей в EEPROM
IDE Arduino IDE
Назначение GPIO NodeMCU Pin
OLED SDA GPIO4 D2
OLED SCL GPIO5 D1
BTN UP GPIO13 D7
BTN DOWN GPIO12 D6
BTN OK GPIO14 D5
BTN BACK GPIO16 D0
OneWire R/W GPIO0 D3
Emulation TX GPIO2 D4

Как прошить

01 Подключи ESP8266 Подключи Wemos D1 Mini или NodeMCU через USB к компьютеру.
02 Открой флешер Нажми кнопку «Прошить устройство» ниже. Нужен Chrome, Edge или Opera.
03 Выбери плату Выбери Wemos D1 Mini или NodeMCU и нажми «Подключить».
04 Прошивка готова Дождись завершения. После — нажми RESET на плате.
